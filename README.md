# Delhivery Integration

Delhivery courier integration for ERPNext with multi-warehouse delivery partner support.

## Install

```bash
bench get-app delhivery_integration <path-or-git>
bench --site <site> install-app delhivery_integration
```

After install, configure **Delhivery Settings** and add **Delivery Partners** to each Warehouse.
